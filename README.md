# 이지프린트

## ⬇ [이지프린트 내려받기 (누르면 바로 받아집니다)](https://raw.githubusercontent.com/yamchaewoo/print-helper/main/%EC%9D%B4%EC%A7%80%ED%94%84%EB%A6%B0%ED%8A%B8.exe)

1. 위 링크를 누르면 `이지프린트.exe` 파일 하나가 받아집니다. 압축 풀기는 없습니다.
2. 받은 파일을 바탕화면처럼 찾기 쉬운 곳에 옮겨 두고 더블클릭하세요.
   - 브라우저가 "흔히 다운로드되지 않는 파일"이라고 하면 **[유지]**를 누르세요.
   - 처음 켤 때 "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]**을 누르세요.
3. 그다음부터는 새 판이 나오면 프로그램이 알아서 받아 둡니다. 다음에 켤 때 새 판으로 바뀌고, 바로 쓰려면 위쪽 **[새 판 받음 · 다시 켜기]**를 누르세요.

- 지금 판: **2026.11.27.1** — PDF 만들기 뒤 보라색 [인쇄]로 만든 PDF를 프린트 인쇄 목록에 넣기
- 학원 양식이 들어 있어 바로 쓸 수 있습니다. 이미 쓰던 `양식.json`이 있으면, exe를 그 파일과 같은 폴더에 두면 그 양식을 그대로 씁니다.
- 프로그램이 새 판을 확인하는 파일: `version.json`
